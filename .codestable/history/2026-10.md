- 2026-10-14 · [功能] Chrome 扩展支持 multipart / FormData 上传接口的元数据判定与 JSON Mock，文件体不采集，未命中或失败保留原始上传。范围：package:chrome-extension、package:mock-console、shared:extension-runtime
  原因：用户确认上传接口因提前原生放行而没有判定日志，并要求用最小复杂度 Mock 其返回；仅调整 multipart / FormData 支持范围，不解析文件、不新增开关或二进制响应能力。
  当前依据：requirements/CONTEXT.md 的上传判定规则；architecture/packages/chrome-extension.md；architecture/shared/extension-runtime.md。
  证据：packages/chrome-extension/src/content-main.ts、content-main.test.ts、extension-chain.test.ts；packages/extension-contract/src/index.ts；packages/mock-console/server/src/extension-routes.ts、extension-routes.test.ts；web/src/components/RequestLogPanel.vue。

- 2026-10-14 · [缺陷] XHR 上传放行使用 send 时的 FormData 快照，等待判定期间的页面修改不再改变真实上传内容。范围：package:chrome-extension
  原因：延迟调用原生 send 时复用可变 FormData 对象，会把发送后的字段修改、删除或新增带入真实请求；保留原对象身份不等于保留发送时内容。仅复制字段和 File 引用，不读取文件数据，上传进度事件保持不模拟。
  当前依据：requirements/CONTEXT.md 的上传判定规则。
  证据：packages/chrome-extension/src/content-main.ts 的 sendXhr；content-main.test.ts 的 FormData XHR pass、throw、timeout 回归先失败后通过，覆盖字段变更、重复字段、顺序、文件名和 File 引用。

- 2026-10-10 · [演进] Chrome 扩展白名单改为页面域名，非白名单页面不包装 fetch 或 XHR，白名单页面不再过滤请求目标域名。范围：package:chrome-extension
  原因：用户报告 GitHub Star 在标签页 Mock 开启时失败、关闭后正常，并明确决定以页面域名限制影响范围；此前请求目标白名单仍会替换无关页面的 fetch，放行并不等于未影响页面。未断言 GitHub 内部失败机制或风控行为。
  当前依据：requirements/CONTEXT.md 的 Chrome Extension 领域规则；architecture/packages/chrome-extension.md。
  证据：packages/chrome-extension/src/content-main.ts、service-worker.ts、content-main.test.ts、extension-chain.test.ts；回归覆盖非白名单页面 API 身份不变、白名单页面跨域请求判定、frame 来源复核、暂停与名单修改。
